# Przemysław Wolny

Technical artist and QA at [BeamNG.drive](https://www.beamng.gmbh/). I also build levels, tools, and photogrammetry materials as **Car_Killer**.

[przemekwolw.github.io](https://przemekwolw.github.io)

## Work

I build world-editor tools, artist pipelines, and content checks for BeamNG.drive, and I help creators get their mods running. The environment work starts from photographs, LiDAR, and real road data, then becomes levels and tileable PBR materials.

## Projects

- [BeamNG Level Importer](https://github.com/PrzemekWolw/BeamNGLevelImporter) imports BeamNG levels and assets into Blender.
- [CK Assets Tools](https://github.com/PrzemekWolw/goDragonCooker) prepares BeamNG textures, materials, and models.
- [GT7 Tone Mapper](https://github.com/PrzemekWolw/GT7ToneMapperUE5Plugin) is a Gran Turismo 7 tonemapper for Unreal Engine 5.
- [Advanced PNG Export](https://github.com/PrzemekWolw/AdvancedPNGExport) is a Paint.NET PNG exporter.
- [Simple GPU-P](https://github.com/PrzemekWolw/Simple-GPU-P) is a small GPU partitioning tool for Windows.

More of the work lives on the site, including the [BeamNG mods](https://www.beamng.com/resources/authors/car_killer.27522/).
